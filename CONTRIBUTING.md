# Contributing

Thanks for wanting to help. Configr's source is not public, so this repository
takes reports, not code.

## Reporting

Open an issue with your Configr version (**Configr → About**), your OS, how you
installed it (Homebrew, Scoop, `.dmg`, `.exe`, AppImage, `.deb`, `.rpm`), what you
did and what you saw. A screenshot helps.

## Pull requests

Everything in this repository is produced by Configr's release workflow, so a pull
request here would be overwritten by the next release. Open an issue instead.
