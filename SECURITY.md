# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub instead: **Security → Report a vulnerability**, or
[open a private advisory](https://github.com/danieldeusing/configr-releases/security/advisories/new).

Say what is affected, how to reproduce it and what an attacker could do with it.
You get an answer within a week.

## Supported versions

Only the [latest release](https://github.com/danieldeusing/configr-releases/releases/latest) gets fixes.
